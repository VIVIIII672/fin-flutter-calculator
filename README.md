# 鰭片顫振計算器

輸入火箭鰭片的尺寸、材料與預期最大速度，算出顫振速度 V<sub>f</sub>，並判定是否達到「最大速度 × 安全係數」。不合格時會列出可達標的厚度、翼展與材料剪切模量。

可以直接上傳（或 Ctrl+V 貼上）OpenRocket 的鰭片設定視窗截圖，自動讀出尺寸與外形。**全部在你的電腦上離線執行，不會上傳任何資料。**

## 下載

## 使用方式

1. **手動輸入**：填入根部弦長 c<sub>r</sub>、尖端弦長 c<sub>t</sub>、單片翼展 b、厚度 t（mm）、剪切模量 G（GPa）、預期最大速度、安全係數與高度。
2. **截圖輸入**：在 OpenRocket 開啟鰭片設定視窗，截圖後拖進程式、按選擇檔案，或直接 Ctrl+V 貼上。
   - **Trapezoidal Fin Set**：截 General 分頁，讀取 Root chord、Tip chord、Height、Sweep length、Thickness。
   - **Freeform Fin Set**：截 Shape 分頁，讀取座標表，並依座標畫出鰭片外形。座標表可在程式裡核對與修改。
3. 看結果：判定、速度對照、G 敏感度、三種公式比較、建議調整、不同材料的比較，以及計算過程。

## 分頁與功能

- **顫振分析**：三種公式（你的公式、固定 ε = 0.25、Bennett 形心修正）、G 下限／標稱／上限、馬赫數外推警告。
- **飛行軌跡**：匯入 OpenRocket 匯出的 CSV（Time、Altitude、Total velocity），逐點計算並找出 G 下限時的最小餘量與最大動壓，可匯出評估結果 CSV。
- **渦流與模態**：Strouhal 渦流脫落頻率、結構模態頻帶與相交速度、單自由度頻率估算。這是篩選，不是顫振預測。
- **安裝與配重**：鰭片質量、合成重心、靜態餘裕、法向力與根部力矩。
- **與 Ansys 比對**：把實驗室 Ansys（流固耦合）或實測的顫振速度記成案例，看三種公式哪個最接近、是否偏樂觀。程式不會自動用比值修正結果。
- **方法與來源**：所有公式、假設與不處理的項目。
- **OpenRocket 檔案**：直接讀 `.ork`（鰭片尺寸、片數、材料、已儲存的模擬結果），一次檢查專案內所有鰭片組。材料只有名稱與密度，G 由名稱對照表給典型值，僅供參考。
- **預設以三種公式中最低的結果判定**；跨音速（Mach 0.8 到 1.2）會標示公式最不可靠的區間。
- **參數掃描**（厚度、翼展）、**氣動加熱估算**與鰭片溫度對 G 的折減、**報告匯出**（HTML，可列印成 PDF）。
- **匯入 Ansys 結果**：Mechanical 的模態頻率表、Fluent 的 Cn 對 Mach 係數表（內插）。
- 公制／英制切換、發射場海拔與當地大氣（氣溫、測站氣壓）、12 筆存檔、JSON 匯出入、列印。輸入有誤時結果會暫停並指出哪個欄位有問題。

部分功能的構想參考自 [STAR-fin-flutter-calculator](https://github.com/andyliuduoduo/STAR-fin-flutter-calculator)；本專案的程式碼為獨立撰寫，沒有使用該專案的程式碼。

### 使用上的注意

- **剪切模量 G 不會從截圖讀取。** OpenRocket 的材料只有密度，沒有 G。請用供應商的規格表，或用 G = E / (2(1+ν)) 估算。碳纖維板的 G 差異很大（約 3 到 30 GPa 以上），不確定時建議用偏低的值。
- **公式的選擇會大幅影響結果。** 預設的公式（含 2G）與 Bennett 形心修正在同一支鰭片上可能差很多：ε = 0.25 時兩者只差 √2（約 41%）；有後掠時，Bennett 修正會把前緣後退算進去，後掠越大算出的顫振速度越低。程式會同時列出三種公式的結果，判斷安全性請以較保守者為準。（舊版說明曾寫「後掠通常使顫振速度更高」，這一點並沒有被 Bennett 的方法支持，已刪除。）
- **馬赫數超過 1.5** 時公式是外推，程式會警告。
- 簡化公式在高馬赫數或較厚的鰭片上誤差可能變大。**本程式只是設計階段的參考，不能取代正式的氣動彈性分析或飛行測試。**
- 截圖辨識使用離線文字辨識（Tesseract），不是 AI。程式讀到的數字請務必和截圖核對。畫面有深色主題、縮放過或模糊時，可能讀錯。

## 公式

```
λ  = c_t / c_r
S  = (c_r + c_t) / 2 · b
AR = b² / S
V_f = a · √( 2G (t/c_r)³ (AR + 2) / (1.337 · AR³ (λ + 1) · P) )   （預設）
```

另外兩種（固定 ε = 0.25、Bennett 形心修正）的式子見程式內的「方法與來源」分頁。

音速 a 與氣壓 P 由「最大速度發生的高度」依標準大氣計算；高度填 0（海平面）是最保守的設定。

## 自己建置

需要 Node.js 22 以上。

```bash
npm install
npm start        # 直接開啟程式
npm test         # 執行自動測試
npm run dist     # 打包成 .exe（需在 Windows 上執行），輸出到 dist/
```

## 發佈新版本（維護者）

推上 GitHub 後，用版本標籤觸發自動打包：

```bash
git tag v1.3.0
git push origin v1.3.0
```

GitHub Actions 會在 Windows 上建置，並把 `.exe` 附到 Releases。也可以在 Actions 頁面手動執行 `Build Windows app`，建置結果會出現在該次執行的 Artifacts。
